# OIBSIP Task 2 - Number Guessing Game (Java)

## 📌 Project Overview
This is a fun **Number Guessing Game** built in Java as part of the **Oasis Infobyte Internship (Java Development)**.

Features:
- ✅ Computer generates a random number between 1–100
- ✅ User guesses the number
- ✅ Hints provided (Too high / Too low)
- ✅ Tracks number of attempts

## 🛠️ Technologies Used
- Java (Core)
- Eclipse IDE

## ⚡ How to Run
1. Clone this repository or download the ZIP.  
2. Import the project into Eclipse.  
3. Run `NumberGuessingGame.java`.  
4. Play the game in the console.
